Deployment Guide (GitHub, Netlify & Shared Hosting)

Follow these quick steps to host Toolswa online with zero 404 errors.

1
Upload to GitHub

Create a repository named toolswa on GitHub. Push all project files ensuring index.html is directly at the repository root.

2
Connect GitHub to Netlify

Log in to Netlify.com, click "Add new site" → "Import an existing project", and choose your toolswa GitHub repo.

3
Exact Netlify Build Settings

• Base directory: Leave EMPTY
• Build command: Leave EMPTY
• Publish directory: . (Root directory)

4
Zero 404 Errors Guaranteed

Toolswa includes pre-configured netlify.toml and _redirects for clean tool URLs (e.g. /tools/pdf-merge) and custom 404 page handling!

Download the ZIP Archive
