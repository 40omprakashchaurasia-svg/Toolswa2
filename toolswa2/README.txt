TOOLSWА - MULTI-TOOLS WEBSITE (SHARED HOSTING DEPLOYMENT GUIDE)
========================================================================

Thank you for downloading Toolswa!
This package is 100% static (HTML5, CSS3, Vanilla JavaScript) and requires
NO Node.js, NO npm, NO PHP, and NO database.

It is ready for instant deployment on any shared web hosting provider,
such as Hostinger, cPanel, GoDaddy, Namecheap, Bluehost, or Apache/Nginx.

------------------------------------------------------------------------
STEP-BY-STEP INSTALLATION (e.g. HOSTINGER / cPANEL)
------------------------------------------------------------------------

1. Log in to your Web Hosting Control Panel (Hostinger hPanel or cPanel).
2. Open the "File Manager".
3. Navigate to the root directory of your website, typically:
   /public_html/
4. Upload this ZIP package ("toolswa-shared-hosting.zip").
5. Right-click the uploaded ZIP and select "Extract" (or "Unzip") directly
   into the public_html directory.
6. Verify that "index.html" is located directly inside public_html/:
   - public_html/index.html
   - public_html/about.html
   - public_html/contact.html
   - public_html/privacy-policy.html
   - public_html/terms.html
   - public_html/404.html
   - public_html/sitemap.xml
   - public_html/robots.txt
   - public_html/css/
   - public_html/js/
   - public_html/tools/
   - public_html/assets/
7. Open your domain name in any web browser (e.g. https://yourdomain.com).
   Your Toolswa website is now live!

------------------------------------------------------------------------
INCLUDED WORKING TOOLS (100% CLIENT-SIDE IN BROWSER)
------------------------------------------------------------------------
1. PDF Merge        (/tools/pdf-merge.html)
   - Combine multiple PDF files with drag and drop and reordering.
2. PDF Compressor   (/tools/pdf-compressor.html)
   - Lossless and raster compression with size comparison.
3. PDF Split        (/tools/pdf-split.html)
   - Extract page ranges or export all pages to ZIP.
4. Image Compressor (/tools/image-compressor.html)
   - Compress JPG, PNG, and WebP with live quality slider.
5. Image Resizer    (/tools/image-resizer.html)
   - Resize by pixels or percentage presets with aspect ratio lock.
6. QR Code Generator(/tools/qr-generator.html)
   - Generate custom QR codes for URLs, text, Wi-Fi, and email.
7. Word Counter     (/tools/word-counter.html)
   - Word, character, sentence, reading and speaking time metrics.
8. GST Calculator   (/tools/gst-calculator.html)
   - Add/Remove GST with 0%, 5%, 12%, 18%, 28% and CGST/SGST split.
